# Football Tic-Tac-Toe

Футбольная версия классической игры «Крестики-нолики», в которой игрокам необходимо знать историю выступлений футболистов за разные клубы.

## Описание

В игре представлены шесть футбольных команд:

1. Barcelona
2. Real Madrid
3. Manchester United
4. Chelsea
5. PSG
6. Juventus

Игроки по очереди выбирают клетку игрового поля и называют футболиста, который выступал за две соответствующие команды. Программа проверяет правильность ответа и позволяет продолжить игру, если назван подходящий футболист.

Новый взгляд на обычные крестики-нолики: они превращаются в игру на знание футбольных клубов, игроков и их переходов между командами.


## Структура проекта

`tictactoe.py` — основной файл с логикой игры.

`players.py` — данные о командах и футболистах, а также функции для проверки ответов.

`check.ipynb` — Jupyter Notebook для проверки и анализа пересечений составов команд.

`requirements.txt` — список необходимых Python-библиотек.

## Используемые технологии

* Python
* Pygame
* Jupyter Notebook
* словари (`dict`)
* множества (`set`)
* функции и условные конструкции

## Запуск

Необходимо установить:

```bash
pip install -r requirements.txt
```

После этого запустите игру:

```bash
python3 tictactoe.py
```
